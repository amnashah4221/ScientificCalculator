📐 Scientific Calculator
A React-based Scientific Calculator with advanced math functions, calculation history, and Light/Dark mode toggle.

🚀 Features
✅ Perform basic operations: +, -, *, /, ^
✅ Use scientific functions:
 • sin, cos, tan (degrees)
 • asin, acos, atan (inverse)
 • log (log base 10), ln (natural log)
 • √ (square root), x², x³, exp (exponent), ! (factorial)
✅ Calculation history with show/hide toggle
✅ Light and Dark themes with toggle button (🌙/☀️)
✅ Smooth button hover effect for both themes
